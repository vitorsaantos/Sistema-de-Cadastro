Sistema de Cadastro de Usuários
Projeto desenvolvido em Python com o objetivo de praticar lógica de programação, organização de código e manipulação de arquivos JSON.

Funcionalidades:
  -Cadastro de usuários.
  -Listagem de usuários cadastrados.
  -Edição dos dados de usuários.
  -Exclusão de usuários.
  -Validação de campos obrigatórios.
  -Validação do número de telefone.
  -Tratamento de entradas inválidas.
  -Salvamento e carregamento dos dados em arquivo JSON.
  -Possibilidade de cancelar operações.

Tecnologias utilizadas:
Python
JSON

Como executar:
  -Clone este repositório.
  -Entre na pasta do projeto.
  -Execute o arquivo menu.py com Python.
